# 奶油云朵信箱

一个面向匿名倾诉与人工回复的网站。倾诉者以随机代号与倾听员交流，可以自行决定是否启用 AI 辅助、随时撤回授权，并管理自己的会话数据。网站采用「云层传送门」视觉风格，支持桌面和手机使用。

**在线体验：** [naiyun.netlify.app](https://naiyun.netlify.app) · **问题反馈：** [GitHub Issues](https://github.com/makesisisi/cream-cloud-mailbox/issues)

## 网站功能

- **匿名交流：** 注册后使用服务端生成的随机代号。倾听员的会话界面及管理员 API 不展示倾诉者的邮箱、真实姓名或登录身份；公开注册只能获得普通用户权限。
- **私密会话：** 倾诉者与倾听员可以双向发送文字和 JPG、PNG、WebP 图片，支持引用回复、短时间内撤回消息，以及发送失败后保留内容重试。图片存于私有存储，读取时再次校验会话权限。
- **可选 AI 辅助：** 每段会话均由倾诉者主动授权，默认关闭。授权后，AI 根据主题、期待、最近对话及最新倾诉附图，为倾听员提供情绪线索、风险提醒和回复建议；结果仅供人工参考，不做诊断、不自动回复。撤回授权会删除已有 AI 分析，不影响正常聊天。
- **倾听员工作台：** 收件箱支持搜索、未读筛选、置顶和标签，并优先显示需要关注的会话。高风险提示配有人工复核、现实安全确认和校内支持交接流程及操作记录。
- **数据自主权：** 倾诉者可以永久删除自己的整段会话，包括消息、图片、AI 结果和附属记录；管理员不能代为删除。已结束的会话保留 90 天，之后由每日定时任务清理；私密图片删除失败会进入重试队列。
- **阅读辅助：** 提供大号文字、增强对比度、减少动效、键盘跳转和路由焦点提示；聊天记录具有可访问的日志语义。

本站提供倾诉与人工支持，**不是医疗服务或紧急救援渠道**。如有即时危险，请拨打 110、120；也可联系全国统一心理援助热线 12356。

## 技术与数据

前端使用 React、Vite 和 React Router。线上身份验证由 Netlify Identity 提供；Netlify Functions 处理权限校验、消息和 AI 请求；Netlify Database 保存会话数据，Netlify Blobs 保存私密图片。普通用户只能访问自己的会话，管理员权限由服务端单独授予。

本地演示模式将账号和聊天数据保存在浏览器中，方便体验双角色流程；线上数据使用服务端存储。AI 所用模型和密钥由服务端环境配置，浏览器不会直接持有密钥。

## 本地运行

需要 Node.js 20。进入仓库根目录后执行：

```powershell
npm.cmd install
npm.cmd --prefix app run dev
```

本地演示无需外部账号或密钥。登录页提供“填入用户账号”和“填入管理员账号”按钮。演示数据仅保存在当前浏览器，不会与线上会话同步。

## 构建与测试

```powershell
npm.cmd run build
npm.cmd test
```

Netlify 构建配置位于 [`netlify.toml`](netlify.toml)，数据库迁移位于 [`netlify/database/migrations`](netlify/database/migrations)。生产部署需要配置 Netlify Identity、Database、Blobs 及 AI 服务端环境变量，并仅在管理端授予倾听员 `admin` 角色。

## 使用边界

- 本项目是轻量倾诉网站，不应收集医疗档案或主动要求用户提供可识别身份信息。
- AI 可能误判，风险提示和回复建议都需要倾听员人工核查。站内危机流程用于记录人工交接，不能替代现实中的专业支持。
- 已完成代码测试和本地界面检查；正式面向更多用户开放前，仍需进行真实跨角色验收、运行环境检查及完整无障碍审计。
